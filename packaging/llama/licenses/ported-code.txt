Code of other projects ported or adapted into llama.cpp and ggml
================================================================

The source files of llama.cpp and ggml compiled into llama-server name the
projects below as the origin of some of their code (ported, adapted or
copied). llama.cpp distributes that code under its MIT License
(llama.cpp-LICENSE.txt in this directory); the notes below repeat what the
source files say about each origin.

-- YaRN --

Used in:  ggml/src/ggml-cpu/ops.cpp and the GPU backends (rope_yarn),
          "based on LlamaYaRNScaledRotaryEmbedding.py from
          https://github.com/jquesnelle/yarn"
License:  "MIT licensed. Copyright (c) 2023 Jeffrey Quesnelle and Bowen Peng."

-- llamafile (Mozilla) --

Used in:  ggml/src/ggml-cpu/llamafile/sgemm.cpp (matrix multiplication
          kernels of the CPU backend), https://github.com/Mozilla-Ocho/llamafile
License:  MIT, "Copyright 2024 Mozilla Foundation" (header of sgemm.cpp)

License:  MIT

-- KoboldCpp --

Used in:  src/llama-sampler.cpp (DRY sampler), "Ported from Koboldcpp,
          original PR: https://github.com/LostRuins/koboldcpp/pull/982
          (Original author: pi6am)"
License:  distributed by llama.cpp under its MIT License. The pull request
          that brought this code into llama.cpp,
          https://github.com/ggml-org/llama.cpp/pull/9702, records the
          permission of its original author (comment of 18 October 2024):
          "We now have the explicit permission from @pi6am to base this
          version on his implementation from koboldcpp. I also added him as
          a co-author on earlier commits for this PR."
