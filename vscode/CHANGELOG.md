# Changelog

## 0.1.0

First release. Requires ChatonLM 0.9.4 or later.

- Chat panel in the side bar with the models of the ChatonLM app: explain, fix,
  write tests, write a commit message; shows before you send whether what you
  share stays on this computer.
- Voice: talk your code through, spoken guided tour of a file or of your
  changes, dictation at the cursor (Shift+Alt+D).
- Autocomplete with a model on this computer (off by default).
- Easy Link: a message on Telegram or Discord when a long task finishes (off by
  default).
- Courses about this project or language, image generation, proofreading of
  comments and documents.
- MCP server for the agents of the editor, with an access of its own limited to
  five tools (off by default).
- ChatonLM's local models in the model picker of VS Code's chat (off by
  default).
